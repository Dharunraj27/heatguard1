# HEATGUARD — Smart Worker Health & Edge AI Safety Dashboard

HEATGUARD is a privacy-preserving wearable safety system for road construction workers and industrial labor forces.

- **Edge AI Processor:** Local risk inference on Arduino UNO Q (STM32H7 + ESP32)
- **Telemetry Link:** LoRa (868MHz Mesh) & Wi-Fi fallback
- **Sensors:** Heart Rate (PPG), SpO₂, Skin Temperature, Ambient Heat Index & Relative Humidity
- **Frontend Stack:** React + TypeScript + Vite + TailwindCSS v4
